## What you should know before using this API surface

Bond Pet Foods runs **no developer program**. There is no developer portal, no API documentation,
no API reference, no changelog, no status page, no SDK, no CLI, no MCP server, no agent card and
no API support channel. Probes of `/openapi.json`, `/swagger.json`, `/api-docs`, `/docs`,
`/graphql`, `/llms.txt` and all eight `/.well-known/` paths returned HTTP 404.

What **does** exist is an incidental but genuinely public, machine-readable API surface: the site
runs on WordPress and WooCommerce, and its REST discovery index at
`https://www.bondpets.com/wp-json/` advertises **970 routes across 57 namespaces**, each of which
answers an HTTP `OPTIONS` request with its own JSON Schema. Two of those namespaces are usable
anonymously and are profiled here. The rest are plugin-contributed administration routes
(Elementor, ElementsKit, RankMath, Jetpack, Klaviyo, Wordfence, FileBird, WooCommerce admin) and
are credential-gated.

Treat this surface as **unmanaged**: it exists because the platform registers it by default, it
carries no versioning or deprecation commitment, and it will change whenever the site's plugins
are updated.

## APIs

- [Store API](https://www.bondpets.com/wp-json/wc/store/v1): WooCommerce Store API. Public,
  unauthenticated reads over the merchandise catalog, categories, tags, brands, attributes,
  reviews and collection facets, plus cart, coupon, shipping-rate and checkout write routes.
  Writes require a `Nonce` header and a `Cart-Token` session.
- [Content API](https://www.bondpets.com/wp-json/wp/v2): WordPress REST API. Public reads over
  news and press posts, pages, media, categories, tags, comments, taxonomies and site search.
  Writes and edit-context reads (`/users`, `/settings`) require authentication and return 401.

## Things an agent will get wrong here

- **Prices are in the smallest currency unit.** `prices.price` of `5500` with
  `currency_minor_unit: 2` is **$55.00**, not $5,500. Always divide by the minor unit.
- **The catalog is merchandise, not pet food.** It holds branded apparel, a tote and a coffee
  donation item — 5 products at time of probe, one of them a live listing literally named
  `Test Product`. The fermented chicken protein Bond Pet Foods makes is a B2B ingredient and
  appears on no API. Do not describe this catalog as their product line.
- **`/wc/store/v1/products/{id}` and `/wc/store/v1/products/{slug}` share one URL template** and
  are told apart only by whether the segment is numeric.
- **Two APIs expose the same product.** `wp/v2/product` carries the editorial fields;
  `wc/store/v1/products` carries the commerce fields. Neither is a superset. Join on `id`.
- **Empty is a correct answer.** Tags, brands, attributes and reviews all return `[]` on this
  store. Do not retry.
- **There is no rate-limit signal at all** — no `RateLimit`, no `X-RateLimit-*`, no `Retry-After`,
  and no published policy. Self-limit.
- **There is no idempotency.** No route of either API accepts an idempotency key. Do not retry a
  write blind.
- **There is no request id** on any response, and no developer support channel to cite one to.
- **Many news posts link off-site.** `link` on a post often points at PR Newswire, Symrise,
  AgFunderNews or YouTube — press coverage, not first-party writing. Check the host before
  attributing.
- **Writes touch a live production store.** There is no sandbox, no test mode and no test data.
